# Start here

This folder is a small vault for a discourse graph: each node is a note that holds one question, claim or piece of evidence, and typed relations join the nodes.

- From a terminal: `kd node claim "A warmer proof makes a more sour loaf"` creates a node, and `kd relate` links two nodes.
- With an agent: ask Claude Code, running in this folder, to use the discourse-graph skill on a note.
- From the editor: select a sentence in a note and press Node.

Run `kd types` to list the node types and the relations this vault allows.
